Overview
--------

The Naver Commerce SDK is designed to make it easy to interact with the Naver Commerce API while providing robust error handling, type safety, and flexibility. This guide will help you understand the SDK's architecture and how to use it effectively in your applications.

Key Topics
----------

:doc:`core-concepts`
   Understand the SDK's architecture, resource organization, and type safety features.

:doc:`sync-vs-async`
   Learn when to use synchronous vs asynchronous clients and how they differ.

:doc:`error-handling`
   Comprehensive guide to exception handling, retry logic, and error recovery.

:doc:`configuration`
   Configure timeouts, retries, base URLs, and other client options.

:doc:`best-practices`
   Production-ready patterns for token management, error recovery, and performance optimization.

Who This Guide Is For
---------------------

This guide is for developers who want to:

- Understand how the SDK works internally
- Choose between sync and async implementations
- Handle errors gracefully in production environments
- Optimize SDK usage for performance and reliability
- Follow best practices for security and maintainability

Prerequisites
-------------

Before reading this guide, you should:

- Have completed the :doc:`../getting-started/index` tutorial
- Understand basic Python concepts (classes, exceptions, async/await)
- Be familiar with REST APIs and HTTP concepts
